# NetSage AI Diagnosis Engine

This folder contains the AI-based diagnosis component of the NetSage project.

The diagnosis engine takes the results generated by the rule checker and
evidence extractor and produces:

- Detected problem
- Root cause
- Explanation
- Recommended solution

The diagnosis flow is:

Evidence
    ↓
Rule Checker
    ↓
Diagnosis Engine
    ↓
Root Cause
    ↓
Recommendation
